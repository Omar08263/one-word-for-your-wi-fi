Entrants send a single word describing their Wi-Fi. A judge model compares the words in private pairs and the funniest, truest one wins the reward.

This entry's word is **Clickbait**: full bars, no internet — the promise of full speed with nothing delivered.

## Run it

```sh
node main.ts
```

The program writes `Clickbait` (exactly 9 bytes, no trailing newline) to `/output/entry.txt` and verifies it with a runtime gate.
